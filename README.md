# Curso de ADK

Este código pertenece al [curso de ADK de EDteam](https://ed.team/cursos/adk).

Cada carpeta corresponde a un ejemplo del curso y los tags del repositorio marcan el estado del código en cada clase:

- `mXcY-inicio` y `mXcY-fin`: inicio y fin de la clase Y del módulo X (módulos 1 a 4).
- `m5cY`: estado de `cafe_app` al terminar la clase Y del módulo 5.

Para ver el código de una clase en particular:

```bash
git checkout m5c3
```
